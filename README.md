# Car-Price-Prediction-ML

🚗 Ford Car Price Prediction using Linear Regression

📌 Project Overview

This project predicts the price of Ford cars using Machine Learning.
A Linear Regression model is trained on a dataset containing various features such as model, year, transmission, mileage, fuel type, and engine size.

---

📂 Dataset

- Dataset: Ford Car Price Dataset
- Features include:
  - Model
  - Year
  - Transmission
  - Mileage
  - Fuel Type
  - Engine Size
  - Price

---

⚙️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

---

🧠 Model Used

- Linear Regression

---

🔍 Data Preprocessing

- Handling missing values
- Encoding categorical variables
- Feature selection
- Train-test split

---

🔍 Encoding Techniques Comparison

- Label Encoding → R² Score: 0.73
- One Hot Encoding → R² Score: 0.84

One Hot Encoding performed better as it avoids false ordinal relationships between categorical variables.

---

📊 Results

- Best Model Performance (R² Score): 0.84 (84%)
- Model explains 84% variance in car prices
- Indicates strong predictive capability
